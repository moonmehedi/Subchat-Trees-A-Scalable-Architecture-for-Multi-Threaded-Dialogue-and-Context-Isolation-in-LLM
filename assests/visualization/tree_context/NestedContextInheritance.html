Figure: Nested Context Inheritance in Subchat Trees with Buffer Summarization & Retrieval Memory

Hierarchical tree showing recursive summary inheritance, buffer eviction to vector store, and semantic retrieval of evicted context.

Formal Context Composition

Node Context: C(v) = Σ_parent(v) ⊕ B(v) ⊕ F(v) ⊕ R(v)
Recursive Summary: Σ(v) = LLM(Σ_parent(v), batch(v))
Grandchild: C(gc) = Σ_child(Σ_parent(Σ_root)) ⊕ B ⊕ F ⊕ R
Isolation: ∀ siblings sᵢ, sⱼ : C(sᵢ) ∩ C(sⱼ) = Ø
Eviction: evict(m) → embed(m) → VDB.store(m, node_id, t)
Retrieval (RAG): R(v) = VDB.search(decompose(q), t_cutoff)
Summary Trigger: trigger ⟺ count ≥ τ ∧ (count − τ) mod δ = 0
Where: B=buffer, F=follow-up, R=retrieved, τ=15, δ=5

Legend

Root — Primary conversation (Depth 0)
Parent — First-level subchat (Depth 1)
Child — Second-level subchat (Depth 2)
Grandchild — Third-level subchat (Depth 3)
Solid — Context inheritance (parent → child)
Dashed purple — Summary generation
Dashed red — Isolation boundary
Dashed teal — Eviction / Retrieval (VDB)
Amber glow — Buffer at capacity
Teal — Vector Store (ChromaDB)

Figure. Nested context inheritance with retrieval-augmented memory. The tree roots at a main topic (Depth 0). Follow-up subchats branch via selected_text. Each node has a fixed-size buffer (n=15). When the buffer fills (count ≥ τ=15), rolling summarization compresses older messages into Σ, and evicted messages are embedded and archived to ChromaDB. Child nodes inherit the parent's Σ — a grandchild at Depth 3 receives Σchild encapsulating Σparent(Σroot). Sibling nodes are fully isolated (Parent A ⊥ Parent B). When a user query implies reference to prior context (e.g., "What did I say about…"), retrieval-augmented generation (RAG) performs semantic search on the vector store to recover evicted information R(v), which is injected into the prompt. Effective context: C(v) = Σparent ⊕ B(v) ⊕ F(v) ⊕ R(v).
