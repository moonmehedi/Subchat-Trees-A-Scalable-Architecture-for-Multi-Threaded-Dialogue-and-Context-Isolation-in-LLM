\section{Synopsis of the Research}
Subchat Trees organizes mixed linear chat into user-controlled branches. Each node uses a local buffer, rolling summary and shared vector memory; children inherit parent context without contaminating parent or sibling branches. Across 309 turns, 59 topics, 43 recall probes, three models and four buffers, the architecture improves context-isolation F1 in every tested configuration without fine-tuning.

\section{Assessment Questions and Answers}

\subsection*{i. Real-world problem, research gap and future contribution}
The project addresses context pollution in linear multi-topic chat through user-controlled branches, branch-aware memory and a structured evaluation benchmark.

\subsection*{ii. Requirements, constraints and functional specifications}
Requirements cover inheritance, isolation, bounded buffers, summarization and retrieval under context, cost, usability and privacy constraints.

\subsection*{iii. Planning, scheduling, resource allocation and risk management}
The work followed six phases from problem study to documentation, using available resources and controls for model failure, leakage, dataset errors and sensitive inheritance.

\subsection*{iv. Investigation and analysis methods}
Deterministic replay, buffer ablation and cross-model experiments compare identical messages using isolation, recall, token, latency, RAG and log evidence.

\subsection*{v. Design, implementation and evaluation}
The architecture combines hierarchical nodes, local buffers, rolling summaries, shared vector memory and isolated child updates. Evaluation against a linear baseline shows higher F1 in every configuration.

\subsection*{vi. Modern engineering and computing tools}
The project uses FastAPI, Next.js, ChromaDB, SentenceTransformers, vLLM, model APIs, Kaggle GPUs and GitHub for modular implementation and reproducible testing.

\subsection*{vii. Societal impacts and stakeholder responsibilities}
Branches can improve accessibility and reduce leakage, while developers remain responsible for transparent inheritance, privacy controls and safeguards.

\subsection*{viii. Ethical and professional issues}
Key ethical issues are privacy, inherited sensitive context and high-stakes reliance. Production systems should expose inheritance, support deletion and state their limitations.

\subsection*{ix. Environmental sustainability}
Bounded buffers, conditional retrieval, reusable embeddings and suitable models can reduce unnecessary computation; the prototype does not measure full carbon impact.

\subsection*{x. Individual roles and team collaboration}
MD Mehedi Hasan Moon coordinated architecture, experiments, analysis and writing. Kabbo Sarker Surjo and Ariful Islam Khan contributed implementation, testing, validation and review.

\subsection*{xi. Communication to technical and non-technical audiences}
Technical communication uses the architecture, benchmark, metrics and implementation; non-technical communication explains how branches provide the right context for each task.
